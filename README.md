# 현금장부 (cas_man)

카드·계좌와 달리 전자기록이 남지 않는 **현금 결제**를 몇 초 안에 기록하고, 언제든 CSV/JSON으로
꺼낼 수 있는 가계부입니다. 입력 항목과 내보내기 형식은 **`일본 자산 관리` 워크북의 「거래내역」
시트**에 그대로 맞춰져 있습니다.

- **오프라인 우선** — 모든 기록은 먼저 기기(IndexedDB)에 저장됩니다. 지하 주차장이든 비행기든
  입력이 됩니다.
- **구글 드라이브 동기화** — 본인 구글 계정의 *앱 전용 숨김 폴더*에 저장되어 여러 기기에서 같은
  장부를 봅니다. 서버도, 가입도, 비용도 없습니다.
- **위젯·단축어 연동** — 홈 화면 아이콘 길게 누르기, iOS 단축어, 안드로이드 위젯에서 URL 하나로
  바로 기록됩니다.
- **어디에나 배포** — 빌드 도구가 필요 없는 정적 파일입니다. GitHub Pages, Netlify, Cloudflare
  Pages, 사내 서버 어디든 그대로 올라갑니다.

## 자산 관리 워크북과의 관계

한 건의 기록이 「거래내역」 시트의 한 행과 1:1로 대응합니다.

| 앱 입력    | 거래내역 열 | 비고                                                     |
| ---------- | ----------- | -------------------------------------------------------- |
| 거래 일시  | `날짜`      | 시각은 CSV의 H열로 따로 나갑니다                          |
| 계좌       | `계좌`      | 기본값 `현금`. 스이카·라쿠텐은행 등도 선택 가능           |
| 금액 + 구분 | `금액`      | 지출·이체는 음수, 수입은 양수로 내보냅니다               |
| 거래처     | `거래처`    |                                                          |
| 범주       | `범주`      | 구분이 수입이면 `수입`, 이체면 `이체` 로 고정됩니다      |
| —          | `출처`      | 이 앱에서 넣은 행은 `현금장부` 로 표시됩니다             |
| 비고       | `비고`      |                                                          |

- 구분은 워크북의 「범주별」 시트와 같은 **지출 / 수입 / 이체** 세 가지입니다.
- 범주와 계좌 목록의 초기값은 워크북에서 실제로 쓰이는 값들이고, 범주는 사용 빈도가 높은
  순서(식비·생활·교통…)로 정렬되어 있습니다. **설정** 에서 자유롭게 추가·삭제할 수 있습니다.
- 월별 요약의 `지출` 은 **이체를 제외**한 금액입니다. 계좌 간 이동은 지출이 아니기 때문입니다.

## 바로 써보기

```sh
python3 -m http.server 8080
# http://localhost:8080 접속
```

동기화 없이도 모든 기능(입력·조회·CSV 내보내기)이 동작합니다.

`file://` 로 열면 ES 모듈과 서비스 워커가 차단되니 반드시 HTTP로 여세요.

## 배포

`main` 브랜치에 푸시하면 `.github/workflows/pages.yml` 이 GitHub Pages로 배포합니다.

**처음 한 번은 저장소 설정이 필요합니다.** 저장소 **Settings → Pages → Source** 를
*GitHub Actions* 로 바꿔주세요. 워크플로의 `GITHUB_TOKEN` 으로는 Pages 사이트를 새로 만들 수
없어서(`Resource not accessible by integration`), 이 단계 전까지는 배포가 실패합니다. 한 번
켜두면 이후 푸시부터는 자동으로 배포됩니다.

다른 호스팅을 쓴다면 저장소 전체를 정적 파일로 업로드하기만 하면 됩니다. 경로가 모두 상대
경로라 `https://example.com/` 든 `https://example.com/ledger/` 든 그대로 동작합니다.

> 서비스 워커와 구글 로그인은 **HTTPS**(또는 `localhost`)에서만 동작합니다.

## 구글 드라이브 동기화 설정

한 번만 하면 됩니다. 무료이고, 결제 계정도 필요 없습니다.

1. [Google Cloud Console](https://console.cloud.google.com/)에서 프로젝트를 만듭니다.
2. **API 및 서비스 → 라이브러리** 에서 **Google Drive API** 를 사용 설정합니다.
3. **API 및 서비스 → OAuth 동의 화면**
   - User Type: **외부**
   - 범위(Scopes)에 `.../auth/drive.appdata` 를 추가합니다.
   - 앱을 게시하지 않고 테스트 상태로 두려면 **테스트 사용자**에 본인 구글 계정을 넣습니다.
4. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 유형: **웹 애플리케이션**
   - **승인된 자바스크립트 원본**: 앱을 여는 주소 (예: `https://d2ceng.github.io`,
     개발용으로 `http://localhost:8080`)
   - 리디렉션 URI는 필요 없습니다.
5. 만들어진 클라이언트 ID(`...apps.googleusercontent.com`)를 앱의 **설정 → 구글 드라이브
   동기화** 에 붙여넣고 **연결** 을 누릅니다.

`drive.appdata` 범위는 이 앱이 만든 숨김 폴더 하나만 볼 수 있습니다. 사용자의 다른 문서·사진에는
접근할 수 없습니다.

### 동기화가 충돌을 처리하는 방식

기록마다 `updatedAt` 타임스탬프와 삭제 표식(tombstone)을 들고 다닙니다. 동기화는 원격 사본을
내려받아 **기록 단위로 최신 것을 남기고**(last write wins) 다시 올립니다. 서버가 중재하지 않아도
여러 기기가 같은 상태로 수렴하고, 한쪽에서 지운 기록이 다른 쪽에서 되살아나지 않습니다.

클라이언트 ID는 브라우저 `localStorage` 에만 저장되고, 액세스 토큰은 메모리에만 둡니다.

## 위젯 · 단축어로 한 번에 기록하기

**설정 → 위젯 · 단축어 연동** 에서 주소를 만들어 복사하세요. 형태는 이렇습니다.

```
https://내주소/?add=1&type=expense&amount=480&category=교통&account=현금&save=1
```

| 파라미터   | 설명                                            |
| ---------- | ----------------------------------------------- |
| `add=1`    | 입력 화면으로 진입                              |
| `type`     | `expense`(기본) · `income` · `transfer`         |
| `amount`   | 금액                                            |
| `category` | 범주 이름. 등록된 범주와 이름이 같아야 선택됨   |
| `account`  | 계좌 이름. 생략하면 기본 계좌(`현금`)           |
| `payee`    | 거래처                                          |
| `memo`     | 메모                                            |
| `save=1`   | 열자마자 즉시 저장 (금액이 있을 때만)           |
| `view`     | `history` 로 주면 내역 화면으로 바로 이동       |

저장 후에는 주소에서 파라미터를 지우므로, 새로고침해도 같은 결제가 두 번 기록되지 않습니다.

- **iOS** — 단축어 앱 → 새 단축어 → *URL 열기* 에 위 주소를 넣고 홈 화면에 추가합니다.
  버스비처럼 금액이 고정된 지출은 `save=1` 로 두면 한 번 탭에 기록이 끝납니다.
- **안드로이드** — 앱을 홈 화면에 설치(PWA)하면 아이콘을 길게 눌러 *지출 빠른입력 / 수입
  빠른입력 / 이번 달 내역* 바로가기를 쓸 수 있습니다. 임의 금액 위젯은 바로가기 생성 앱에서 위
  주소를 등록하세요.
- **공유하기** — 다른 앱에서 금액이 담긴 텍스트를 공유하면 숫자를 뽑아 금액으로 채웁니다.

## 내보내기 / 가져오기

- **거래내역 CSV** — `날짜, 계좌, 금액, 거래처, 범주, 출처, 비고` 다음에 `시각, id, updatedAt`
  이 붙습니다. **A~G열이 「거래내역」 시트와 완전히 같은 순서**라, 그 범위를 복사해 시트 끝에
  붙여넣으면 됩니다. UTF-8 BOM이 붙어 있어 엑셀에서 한글이 깨지지 않습니다.
- 반대로 시트에서 A~G열만 복사해 CSV로 저장한 뒤 가져오기 해도 됩니다. `금액` 의 부호와 `범주`
  로부터 구분을 되돌려 읽습니다.
- **JSON** — 삭제 표식까지 포함한 무손실 백업입니다. 기기를 옮길 때 사용하세요.
- 가져오기는 두 형식을 모두 받으며, `id` 가 같으면 최신 `updatedAt` 쪽이 남습니다.

## 표시 통화

**설정 → 표시 통화** 에서 円(기본) · 원 · $ 중에 고를 수 있습니다. 금액은 정수로만 저장되므로
통화를 바꿔도 기록은 변하지 않으며, 키패드의 0 묶음 키가 통화에 맞춰 `00`/`000` 으로 바뀝니다.

## 구조

```
index.html              화면 구조
assets/app.js           UI 컨트롤러
assets/store.js         IndexedDB 저장소 + 범주·계좌 목록 + 병합 규칙
assets/sync.js          구글 드라이브 appDataFolder 동기화
assets/transfer.js      CSV/JSON 내보내기·가져오기
sw.js                   오프라인 캐시
manifest.webmanifest    PWA 설치·바로가기·공유 대상
tools/make_icons.py     아이콘 생성 (표준 라이브러리만 사용)
tests/                  병합 규칙과 거래내역 CSV 왕복 테스트
```

의존성이 없으므로 `npm install` 은 필요 없습니다.

## 테스트

```sh
node --test tests/*.test.mjs
```

아이콘을 다시 만들려면:

```sh
python3 tools/make_icons.py
```
