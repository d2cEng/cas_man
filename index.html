계정

클라우드 동기화

구글 계정으로 로그인하면 기록이 본인 Firestore 영역에만 저장되어 폰·PC 어디서 열어도 같은 장부를 봅니다. 입력은 기기에 먼저 저장되므로, 로그인하지 않아도 앱은 그대로 동작합니다.

로그인되지 않음

Firestore 보안 규칙이 쓰기를 막고 있습니다. 아래 블록을 Firebase 콘솔 → 규칙 의 match /databases/{database}/documents 안쪽에 추가하고 게시하세요. 기존 규칙은 그대로 두면 됩니다 — 규칙은 OR로 평가되어, 새 경로용 허용을 더하는 것이 기존 권한을 좁히지 않습니다.

장부 설정

현금 기초 잔액

이 앱을 쓰기 시작한 시점에 지갑에 있던 현금입니다. 넣어두면 잔액이 실제 지갑과 바로 맞아떨어져, 차이가 곧 빠뜨린 지출이 됩니다. 워크북과 같은 방식으로 거래처 잔고신고 · 범주 수입 · 비고 잔고 인 기록 한 건으로 남습니다.

계좌

지출·수입은 기본 계좌로, 이체는 아래 짝으로 시작합니다. 이체는 은행에서 현금 뽑기가 가장 잦아 그렇게 맞춰 두었습니다.

범주

지출에만 쓰입니다. 수입과 이체는 워크북과 같이 범주가 하나로 고정됩니다. 초기 목록은 워크북에서 실제로 쓰는 값이고, 자주 쓰는 순서로 정렬해 두었습니다.

표시 통화

표시에만 쓰입니다. 금액은 정수로 저장되므로 바꿔도 기록은 변하지 않고, 키패드의 0 묶음 키만 00/000 으로 따라 바뀝니다.

종합가계부로 넘기기

내보내기 / 가져오기

거래내역 CSV — A~G열이 워크북 「거래내역」 시트와 같은 순서라 그대로 붙습니다. H열 잔액 은 계좌별 누계로, 지갑과 대조하라고 붙인 파생값입니다. 파일명에 기간·건수가 들어가 archive/ 에 그냥 쌓아도 됩니다.

인수인계 요약 — 건수·합계·최종 잔액을 마크다운으로 복사합니다. 코워크 세션에 붙여넣어 독립 검산의 대조값으로 쓰세요.

JSON 백업 은 id까지 담은 무손실 사본입니다(기기 이전용). 가져오기는 두 형식을 다 받고, 같은 파일을 두 번 넣어도 중복되지 않습니다.
